# Generative AI Workflows

This repository documents practical experiments, model evaluations, and production observations related to generative imaging and AI-assisted video creation.

## Repository Structure

| Path | Purpose |
| --- | --- |
| [`workflows/comfyui/`](workflows/comfyui/) | Reusable ComfyUI workflow files and their setup notes. |
| [`prompts/image/`](prompts/image/) | Image-generation prompts, variants, and observed results. |
| [`prompts/video/`](prompts/video/) | Text-to-video and image-to-video prompts, including shot guidance. |
| [`model-tests/`](model-tests/) | Structured model evaluations, comparisons, and benchmarks. |
| [`troubleshooting/`](troubleshooting/) | Reproducible fixes and debugging notes for common problems. |
| [`docs/`](docs/) | Longer guides, production notes, terminology, and supporting documentation. |

I focus on practical production-oriented testing, including:

- Image quality
- Prompt accuracy
- Character consistency
- Composition and typography
- Workflow integration
- Performance and usability
- Suitability for professional media production

Selected workflow notes, comparisons, and creative experiments will be added over time.

## How to Use This Repository

1. Start with the directory that matches your task.
2. Read that directory's `README.md` for its documentation format and expectations.
3. Download or copy the relevant workflow, prompt, test, or troubleshooting note.
4. Check dependencies, model versions, settings, and known limitations before reproducing an experiment.
5. Record meaningful changes and results so experiments remain comparable over time.

When adding material, follow the naming and submission guidelines in [`CONTRIBUTING.md`](CONTRIBUTING.md). Repository changes are tracked in [`CHANGELOG.md`](CHANGELOG.md).
