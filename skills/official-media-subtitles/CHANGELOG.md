# 更新记录 / Changelog

## 2.0.0 — 2026-10-24

本版本调整默认字幕编辑规则，因此按仓库约定升级主版本号。

### 默认行为变化 / Changed
- 全部字幕在初稿后必须再做一次基于上下文的“语义减法”，不依赖固定水词表，也不等待用户逐项指出；删除与否由句子的实际意义决定。
- 增加完整中文语法与规范用字复核，逐处按句法功能区分“的／地／得”，并覆盖跨字幕条的完整句子。
- 用户指定的定稿继续拥有文字、删留、标点和分段权威；模型审计发现的问题须另行报告，未经要求不得反向改写定稿。
- 两版字幕按正文顺序而非字幕序号对齐，并在交付前检查首尾、遗漏、重复和误替换。

### 不变项 / Unchanged
- 保留源媒体时间轴；删除口语成分后留下空档，不整体平移后文。
- 不用背景资料或自动识别结果覆盖说话人的实际原意、立场和确定程度。
- SRT 格式、禁用逗号句号的约定以及校验器命令行接口不变；未增加运行依赖。

### 升级说明 / Migration
1.x 使用者应先备份并比较已安装副本，再完整替换本技能目录。若用户已有项目级规则，应重点核对“语义减法”的删留边界、定稿权威和“的／地／得”复核要求；不要只复制 VERSION 文件。

### 验证范围 / Validation
发布前核对 VERSION、SKILL.md 元数据和 README 版本一致；通过技能结构检查、Python 语法检查、SRT 校验器有效样例与错误样例测试，并检查公开包不含具体节目、采访原话、个人路径或凭据。结构和脚本测试不能替代真实音频复听与人工语义审核。

## 1.0.0 — 2026-09-15

首次为公开字幕 Skill 建立版本基线。此前公开发布的未编号版本与此版本使用相同的字幕处理规则和校验脚本。

### 本次新增 / Added
- VERSION 文件，以及 SKILL.md 的 metadata.version。
- 首页版本标记、版本号约定、使用者升级指令和回退方法。
- 明确区分 Git 仓库副本更新与 WorkBuddy 已安装副本更新。

### 功能与依赖 / Behavior and dependencies
- 字幕编辑规则、时间轴原则和 Python 校验逻辑没有改变。
- 不捆绑语音转写引擎；Python 3 和可选 ffprobe 的要求不变。
- 未配置自动检查更新或后台安装。

### 从未编号版本升级 / Migration
先比较已安装文件，备份本地修改，再完整安装新版。缺少 VERSION 表示未标记版本，不代表技能损坏。

### 验证范围 / Validation
技能结构检查通过；首次公开版的校验器已通过有效 SRT、禁用标点和时间重叠测试。本次只增加版本信息与文档，没有新增音视频业务测试；WorkBuddy 中的实际识别与转写效果仍需使用者验证。
