# ComfyUI Workflows

Store reusable ComfyUI workflow exports and the notes required to reproduce them in this directory.

For each workflow, include:

- A descriptive workflow filename.
- Its purpose and expected output.
- Required models, custom nodes, and version information.
- Important generation settings and input requirements.
- Known limitations and representative output notes.

Do not include model weights, private assets, credentials, or other large binary dependencies.
